Smart Tasks for Windows: preview

The window shows the real app UI, running in local mode so you can add tasks. Everything around it (taskbar, tray, toasts) is a mock of what the Rust app adds.

Try it

Badge 3

Right-click the tray icon (bottom right) for its menu. Left-click toggles the window.

How the desktop app behaves

  • Window: fixed 400×600, the same screens as the extension popup.
  • Close (×) hides it to the tray so sync and reminders keep running. Quit from the tray menu.
  • Global shortcut Ctrl+Alt+K opens it from anywhere. The extension's Ctrl+Shift+K stays free for Chrome.
  • Taskbar badge: due-today/overdue count (green/red), or unread agent notifications (purple). Same rules as the toolbar badge.
  • Reminders: Windows toasts with Mark done and Snooze 10 min.
  • Start with Windows (on by default, toggle in the tray) launches straight to the tray.
  • Sync: same account, API and live WebSocket updates as the extension, so tasks match across Chrome and desktop.

Not carried over

  • Right-click "Add task" on web pages (browser only).
  • Self-update of unpacked extension folders. The desktop app will get its own updater later.
  • Google sign-in opens Google in a small app window instead of Chrome's popup. It needs testing in the real build.

Build target

  • Tauri 2 (Rust) on the WebView2 runtime that ships with Windows 11.
  • Release profile tuned for size: LTO, opt-level "s", strip, abort on panic.
  • Aim: a ~4–6 MB exe and ~2–3 MB installer, compared with ~150 MB for Electron.
